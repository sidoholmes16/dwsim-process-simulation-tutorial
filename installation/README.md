# DWSIM Installation Guide

This guide explains how to download and install DWSIM on a Windows computer.

## 1. Software Information

- **Software:** DWSIM
- **Version:** 10.2.12
- **Operating System:** Windows 10/11 (64-bit)
- **Architecture:** x64 (Intel/AMD)

## 2. Download DWSIM

Download DWSIM from one of the official sources below.

- **Official Download Page:** https://dwsim.org/index.php/download/
- **GitHub Releases:** https://github.com/DanWBR/dwsim10/releases

### Recommended Download

For most Windows computers with Intel or AMD processors, select:

**DWSIM-10.2.12-win-x64-setup.exe**

[Download DWSIM from GitHub Releases](https://github.com/DanWBR/dwsim10/releases)

Open the latest release and locate the Windows x64 installer in the Assets section.

## 3. Installation Steps

1. Download the Windows x64 installer.
2. Open the downloaded `.exe` file.
3. Follow the installation wizard.
4. Accept the required options and complete the installation.
5. Launch DWSIM from the Start menu.
6. Create a new simulation to verify that the installation works.

## 4. System Requirements

- Windows 10 or later (64-bit).
- A 64-bit Intel/AMD or ARM-compatible computer with the appropriate installer.
- At least 4 GB of RAM; 8 GB is recommended.
- Approximately 1 GB of free disk space.

## 5. Important Notes

- Always download DWSIM from its official website or official GitHub releases.
- Check the release page for newer versions and compatible installation packages.
- The version shown in this guide may be updated as new releases become available.
